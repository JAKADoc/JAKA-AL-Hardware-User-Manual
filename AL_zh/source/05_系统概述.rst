机器人系统概览
++++++++++++++

CAB L、CAB H与机器人搭配使用时，所需部件如下图。

.. figure:: ../../images/05_系统概述/机器人系统组成部件.*
   :width: 14.87cm
   :align: center

   搭配CAB L/H系统部件

CAB LiteAC与机器人搭配使用时，所需部件如下图。

.. figure:: ../../images/05_系统概述/CAB_LiteAC系统部件.*
   :width: 14cm
   :align: center

   搭配CAB LiteAC系统部件

1. 手柄：配备急停按钮和三位置使能开关。用于启动或关闭机器人系统、配置参数及控制运动。
2. 控制柜：内置核心计算单元及多种电气接口。
3. （自备）路由器与网线：控制柜内置无线模块，可接入操作终端至其无线局域网（SSID为控制柜序列号，默认密码为JKadmin123）。亦可使用有线示教器，或将控制柜网口连接至路由器，操作终端连接至该路由器的无线网络。建议为机器人单独配置路由器，避免与其他设备冲突。
4. 控制柜电源线：为控制柜供电。
5. 机器人本体：负责执行主要运动，实现预定动作。本体末端装有状态指示灯、拖拽按钮及工具I/O接口。
6. 机器人连接线：用于连接机器人与控制柜。

搭配CAB LiteDC时，可集成于AGV等移动平台，支持利用AGV内置的48V动力电池进行供电。该控制柜体积紧凑，便于集成。所需的部件如下图所示。

.. figure:: ../../images/05_系统概述/CAB_LiteDC系统部件.*
   :width: 14cm
   :align: center

   搭配CAB LiteDC系统部件

1. 手柄：配备急停按钮和三位置使能开关。用于启动或关闭机器人系统、配置参数及控制运动。
2. 控制柜：内置核心计算单元及多种电气接口。
3. （自备）路由器与网线：控制柜内置无线模块，可接入操作终端至其无线局域网（SSID为控制柜序列号，默认密码为JKadmin123）。亦可使用有线示教器，或将控制柜网口连接至路由器，操作终端连接至该路由器的无线网络。建议为机器人单独配置路由器，避免与其他设备冲突。
4. 机器人本体：负责执行主要运动，实现预定动作。本体末端装有状态指示灯、拖拽按钮及工具I/O接口。
5. 机器人连接线：用于连接机器人与控制柜。
6. 直流电源：控制柜采用直流供电，推荐使用48V电源。

.. _部件概览:

部件概览
++++++++

机器人主要由六个关节和两个铝制臂杆组成，基座用于机器人本体和底座连接，工具端用于机器人与末端执行器连接。末端执行器可在机器人的工作空间内做平移和旋转运动。

机器人主体包括6个旋转运动关节，以及大臂与小臂两个连接臂杆。在机器人末端配有指示机器人状态的指示灯以及暂停/恢复按钮，在工具法兰外侧配有两个按钮。

.. _控制柜:

控制柜
========

CAB V3具有CAB L、CAB H、CAB LiteAC 和CAB LiteDC 四种型号，其中 CAB L、CAB H为标准型控制柜，采用交流供电，CAB LiteAC和CAB LiteDC 为紧凑型控制柜，可集成在 AGV 中，其中CAB LiteDC采用直流供电。

控制柜具有以下功能：

- 为机器人供电
- 提供手柄连接接口
- 提供通过网线或Wi-Fi连接操作终端的网口
- 提供多种不同类型输入和输出接口

.. _手柄:

手柄
========

手柄具有以下功能：

- 控制机器人急停
- 控制机器人运动至特定姿态
- 启停程序
- 控制控制柜上下电、机器人上下电和上下使能
