.. _运输条件:

运输条件
========

机器人运输时需要使用原包装，因此如果有运输需求，请务必保存好原包装。

机器人吊装时，应采取相应措施进行定位，避免产生意外运动造成损伤。操作步骤参考 :ref:`吊起` 。

从机器人的包装中将机器人移至安装位置时，应由至少2人同时扶住机器人直至机器人底座的所有螺钉全部紧固完成。

.. warning::

   - 确保抬升设备时作业人员背部或身体其他部位不会过分负重。使用适当的抬升设备。JAKA不对设备运输过程中产生的损害负责。
   - 请遵守各地区及国家有关搬运法规。
   - 确保安装机器人时严格遵守安装指示。

.. attention::

   如果运输机器人时未使用其原始包装，所有保修都将失效。

.. _保存条件:

保存条件
========

| 1. 保存温度：-10~50℃（14~122℉）
| 长期保存时，为了维持其可靠性，建议将温度维持在25±10℃（59~95℉）内。请避免急剧的温度变化（10℃/h（18℉/h）以上）。

| 2. 保存湿度：20~85% RH
| 长期保存时，为了维持其可靠性，建议将湿度维持在45~65%内。保存时避免结露或发霉。

| 3. 防静电
| 保存在极端干燥的状况下容易产生静电，静电放电时的冲击可能破坏半导体。请放入防静电袋中保存。

| 4. 其他环境条件
| 请保存在不会产生有毒气体、污垢、尘埃较少的环境中。保存期间请勿在其上面放置重物。

.. _重要安全说明-1:

重要安全说明
============

.. warning::

   - 确保机器人本体正确并安全地安装到位。
   - 安装表面必须是防震的，并有足够的承载能力。

.. warning::

   - 确保末端执行器正确并安全地安装到位。
   - 确保工具安全，不会有零件意外坠落造成危险。

.. warning::

   - 确保控制柜和线缆不接触液体，潮湿的控制柜可导致人员触电危险甚至死亡。
   - 控制柜不得暴露在灰尘或潮湿程度超出IP44等级的环境下，密切注意存在导电灰尘的环境。

.. warning::

   如果机器人泡在水中超过一定时间，则可能会被损坏。机器人不应安装在水中或潮湿环境中。

.. _安装平面要求:

安装平面要求
------------

机器人应安装在坚固的安装平面上。该平面不仅需要承受 :ref:`机器人底座可承受力和转矩` 所述的扭矩，还应具备足够的刚度，以防止因形变或振动导致工具中心点（TCP）出现显著偏差，建议机器人的安装平面厚度至少为20 mm（0.787 in），且材质为钢。此外，尽量避免将机器人本体直接安装在空箱上，这样容易引起共振，发出异响。如果机器人安装在线性轴或活动的平台上，则安装基座的加速度应很低，因为高加速度会导致机器人误报碰撞而停止运行。

请注意机器人在正常运行时安装平面需承受的扭矩，数据参考 :ref:`机器人底座可承受力和转矩` 。

.. warning::

   在安装机器人过程中，不可连接电源。

.. attention::

   - 不同角度安装机器人时，必须在软件中更新安装角度，具体操作见 |软件| 软件用户手册。
   - 出厂测试可能在安装孔内留下装配痕迹。若发现锈蚀、表面损伤或无法确认的痕迹，应按质量验收文件判定，必要时联系 JAKA 技术服务人员；不得仅以“正常现象”为由继续安装。
   - 如果未牢固地将机器人固定在底座上，则机器人的机械结构可能不稳定，而且可能会造成翻倒。
   - 倒装或侧装时，应保证安装平面的刚性和稳定性，将机器人安装在强度和刚性不足的墙面或天花板上非常危险，可能会由于机器人振动或跌落导致重伤或机器人系统重大损害。
   - 机器人要使用在与其IP 等级相匹配的环境中，有助于减少故障且延长机器人的使用寿命。

.. _数字输入:

数字输入
--------

TIO支持2路用户DI数字输入接口，NPN、PNP型兼容，可在App中进行配置，具体操作见 |软件| 软件用户手册。

**干接点型输入** 

当将DI输入配置成NPN型时：

干接点型输入（即开关型输入）一端连接TIO中GND（灰色线），另一端连接DI数字输入（蓝色或绿色线）。

.. figure:: ../../images/07_运输及调试/NPN型干接点输入接线.*
   :width: 9.67cm
   :align: center

   NPN型干接点输入接线

当将DI输入配置成PNP型时：

干接点型输入（即开关型输入）一端连接TIO中24V（红色线），另一端连接DI数字输入（蓝色或绿色线）。

.. figure:: ../../images/07_运输及调试/PNP型干接点输入接线.*
   :width: 9.72cm
   :align: center

   PNP型干接点输入接线

**连接NPN/PNP型设备**

连接NPN/PNP型数字量输入设备时，接线方式：V+连接TIO中的24V（红色线），0V连接TIO中的GND（灰色线），信号线连接TIO中的数字输入（蓝色或绿色线）。

.. figure:: ../../images/07_运输及调试/连接外部NPN设备接线.*
   :width: 8.55cm
   :align: center

   数字输出接口接线

| A 外部负载或输入设备
| B TIO V3
| C 主电路

数字输出
--------

数字输出接口为NPN/PNP型输出时，采用开漏输出，最高支持连续1A电流能力输出。接线方式：外部输入端口连接TIO中的数字输出（黄色或粉色线），外部V+连接TIO中的24V（红色线），外部0V连接TIO中的GND（灰色线）。

.. _机器人上下使能:

机器人上下使能
==============

有以下两种方式控制机器人上电、上使能、下电和下使能。

- 通过手柄控制
- 通过 |软件| 控制

通过手柄控制机器人的操作步骤如下：

使用手柄使能机器人流程如下：

#. 控制柜开机：短按开关按钮，蜂鸣器响，控制柜开机。
#. 手柄解锁：长按锁定按钮3s，锁定提示灯熄灭，手柄解锁。
#. 机器人上电：短按使能按钮，等待机器人末端指示灯变为蓝色，机器人上电。
#. 机器人上使能：先按住锁定按钮，再同时按使能按钮，机器人末端指示灯变为绿色，机器人上使能。
#. 手柄锁定：手柄解锁状态下无法通过App控制机器人，因此需将手柄锁定。长按锁定按钮3s，锁定提示灯为橙色呼吸，手柄锁定。此时可使用App控制机器人。

使用手柄关闭控制柜流程如下：

#. 手柄解锁：长按锁定按钮3s，锁定提示灯熄灭，手柄解锁。
#. 机器人下使能：先按住锁定按钮，再同时按使能按钮。机器人末端指示灯变为蓝色，机器人下使能。
#. 机器人下电：短按使能按钮，等待机器人末端指示灯熄灭，机器人下电。
#. 控制柜关机：长按开关机按钮3s以上，手柄蜂鸣6~7次，控制柜关机。关闭控制柜后，请勿立即断电，待手柄灯熄灭，并等待5~10s后，可断开电源。

.. attention::

   非紧急状态下，必须严格遵循标准启停流程操作机器人系统。严禁强制断电，否则将导致数据丢失及系统可靠性风险。

.. _启动前准备:

启动前准备
==========

在调试机器人之前，应验证以下项目：

- 验证紧急停止装置和操作员防护装置。
- 根据相关标准，设计防护装置以确保机器人在不偏离预定路径的情况下停止（停止类别1）。
- 在手动低速模式下，使机器人逐步接近预设工作空间边界，确认安全限制能在越界前按预期阻止运动；禁止强制越过限制。
- 在手动低速模式下，使各关节逐步接近设定的最大和最小角度，确认关节限制能按预期阻止继续运动；禁止强制越过机械或软件限制。

.. _启动机器人:

启动机器人
==========

机器人首次运行时，可能因接线错误、安装紧固不当或参数设置不匹配导致机器人做出预期之外的动作。

.. warning::

   设备意外运行风险：

   - 确认机器人已正确、牢固安装。
   - 采取必要措施，确保机器人运动部件不会发生非预期运动。
   - 确认急停装置功能正常且位于操作区域可触及范围内。
   - 启动系统前，确认运动路径无障碍物且系统已就绪。
   - 首次启动测试应以低速运行。

   ..

      未遵循上述要求可能导致人员死亡、重伤或设备损坏。

若机器人电源因断电或故障意外中断，机器人将无法以受控方式减速停止。

.. warning::

   设备意外运行风险：

      | 需确保制动器失效状态下的运动不会造成人员伤害或设备损坏。
      | 未遵循上述要求可能导致人员死亡、重伤或设备损坏。

.. warning::

   高温表面风险：

   - 禁止在高温表面附近放置易燃或热敏感部件。
   - 通过满负荷条件下的试运行，验证系统散热性能是否符合要求。

   ..

      未遵循上述要求可能导致人员死亡、重伤或设备损坏。

.. _调试机器人:

调试机器人
----------

请按以下步骤调试机器人：

#. 遵守本手册中的所有操作说明。
#. 运行前确认负载符合机器人的额定载荷要求。
#. 通过 |软件| 连接机器人，操作详情参见 |软件| 软件用户手册。
#. 配置机器人安装参数，操作详情参见 |软件| 软件用户手册。
#. 验证各关节校准状态及位置方向。
#. 在手动操作界面验证世界坐标系方向，操作详情参见 |软件| 软件用户手册。

   .. note::

      世界坐标系取决于安装方位。

#. 根据应用场景的安全要求配置碰撞保护参数，配置方法参见 |软件| 软件用户手册。
#. 以低速执行初始测试，验证机器人功能正常。
#. 确认实际运行速率不超过验证所得最大运行速率的 80%。

   .. note::

      若验证所得最快周期时间为 8 s，则实际周期时间应不小于 10 s。周期时间与运行速率成反比，二者不得混用。

#.  （可选）为手柄的“复位”按钮配置初始位置。手柄操作说明详见 :ref:`手柄说明` 。初始位置配置方法参见 |软件| 软件用户手册。
#.  （可选）存在多套机器人系统时，可为机器人设置唯一名称以便识别，配置方法参见 |软件| 软件用户手册。

.. _运行默认程序:

运行默认程序
------------

有以下两种运行默认程序的方式：

- 通过手柄运行
- 通过 |软件| 软件运行

若通过手柄运行默认程序，需短按手柄上的 **启动/停止** 按钮。

若通过 |软件| 设置并运行默认程序，请参见 |软件| 软件用户手册。

.. _安装末端执行器:

安装末端执行器
==============

末端执行器安装步骤：

#. 将末端执行器固定到机器人工具法兰安装孔位上 (**1**)

    - 节圆直径符合DIN ISO 9409-1标准，为50 mm（1.97 in）：4个M6 螺纹孔（ **2** ），拧紧扭矩：13 N·m（115.05 lbf·in），螺钉性能等级不低于12.9。
    - 节圆直径为50 mm（1.97 in）：1 个安装孔直径为6 mm，公差等级 H7 (**3**)

    .. figure:: ../../images/07_运输及调试/AL末端法兰.*
       :width: 9cm
       :align: center

       末端法兰

    .. note::

       机器人末端法兰尺寸信息参考 :ref:`机器人法兰尺寸` 。

#. 在 |软件| 中设置负载，设置负载步骤参考 |软件| 软件用户手册。

.. note::

   - 请严格遵守影响机器人负载能力的重量及距离限制。
   - 根据ISO9409-1：2004，定位销孔的中心应与机械接口坐标系(GB/T16977-2019)+Xm的轴线对齐，JAKA机器人末端执行器定位销孔的中心在此基础上顺时针偏移45°。
