.. _概述:

概述
====

本章介绍控制柜上的连接接口。

.. caution::

   将连接端子连接到控制器之前，请务必检查连接端子是否脏污或损坏。清洁或更换损坏的部件。

.. _接地与屏蔽连接:

接地与屏蔽连接
==============

.. _接地要求:

接地要求
--------

控制器柜接地必须来自电力网供电PE。

- 接地电缆的颜色应为绿黄色。
- 控制器柜、机械手和外围设备的接地必须相同，最好是一个等电位接地网（网格）。
- 接地连接点必须具有稳定的金属间结合，如螺丝固定。必须清除接触表面的油漆、灰尘、铁锈和其他绝缘材料。

关于控制柜内部电源接地连接的标志要求，请参见UL508C。关于应当如何设计接地系统的更多详情，请参见IEC 61000-5-2。关于PE的横截面积详情，请参见IEC60204-1。

电源连接
========

.. _操作前提:

操作前提
--------

在将输入电源接入控制柜之前，必须满足以下条件：

- 必须安装外部断路器或保险丝。
- 控制柜必须连接到保护接地。
- 必须安装剩余电流设备（RCD）。

.. _安全挂锁:

安全挂锁
--------

.. _远程开关机接口:

远程开关机接口
--------------

远程开关机接口位于P1的pin7和pin8接口。通过此接口，可在不使用 |软件| 或手柄时，开启或关闭控制柜。用户可以将远程开关机接口接入PLC系统，远程控制机器人控制柜的开关机。

当远程开关机接口接收到24V电源时（参考地为V–）有效。此接口与手柄 **开关按钮** 功能相同。

.. _紧急停止接口:

紧急停止接口
------------

紧急停止接口位于控制柜前面板P1的pin3和pin4接口，可通过此接口实现紧急停止。紧急停止接口具有双路冗余设计，即任何一个信号有效时，都可启用该功能。如需使用外部安全设备请选择支持双通道设计的设备。用户可根据实际安全要求，接入安全门、安全光幕、传感器等。

在不使用手柄的情况下使用机器人时，需要连接额外的急停装置，可使用控制柜前面板紧急停止接口连接紧急停止开关以确保安全。

.. warning::

   - 如果手柄与机器人断开连接，手柄上的紧急停止按钮则不再有效。必须将断连的手柄从机器人附近移走。
   - 急停接口的供电必须由控制柜内部通过 P1 接口的 pin11 和 pin12 提供，严禁使用外部电源供 电。使用外部电源可能损坏控制柜内部安全电路，造成设备失效或安全隐患。

     - DO7 & DO8

     - DO9 & DO10

扩展通讯
========

.. _EtherCAT拓展I-O:

EtherCAT拓展I/O
---------------

CAB V3控制柜支持连接外部扩展板卡，以实现机器人做EtherCAT主站。支持以下两个型号的板卡：

- 艾莫迅EC1A-IO16R-AM6，简称EC1A。支持16路数字输入（NPN/PNP）、16路继电器输出、4路模拟输入、2路模拟输出，模拟输入/输出的电压和电流范围为0~10V，0~20mA。
- 艾莫迅EC3A-AE0830，简称EC3A。支持8路模拟输入，电压和电流范围为0~10V，0~20mA，精度为16位。

最多支持两个板卡同时运行，两个板卡之间串联连接。有如下六种配置：

- EC1A
- EC3A
- EC1A+EC1A
- EC3A+EC3A
- EC1A+EC3A
- EC3A+EC1A

.. caution::

   软件配置的板卡顺序必须与实际硬件连接的顺序保持一致。例如，若EC1A连接至控制柜，EC3A串联于EC1A之后，则软件中的配置顺序也应为EC1A在前，EC3A在后。

若连接一个板卡，接线方式如下：

- 扩展板卡的24V连接至控制柜前面板的V+。
- 扩展板卡的0V连接至控制柜前面板的V–。
- 扩展板卡的RJ45接口连接至控制柜底面板的LAN2网口。

若连接两个板卡，接线方式如下：

- 第一个扩展板卡的24V连接至控制柜前面板的V+。
- 第一个扩展板卡的0V连接至控制柜前面板的V–。
- 第一个扩展板卡的RJ45接口连接至控制柜底面板的LAN2网口。
- 第二个扩展板卡的24V连接至控制柜前面板的V+。
- 第二个扩展板卡的0V连接至控制柜前面板的V–。
- 第二个扩展板卡的RJ45接口连接至第一个扩展板卡的RJ45接口。

接线完成后，需在 |软件| 软件配置，具体操作见 |软件| 软件用户手册。

.. _Modbus-RTU主-从站:

Modbus RTU主/从站
-----------------

CAB V3控制柜支持连接外部扩展板卡，以实现Modbus RTU通讯，机器人既可做主站，也可做从站。

推荐板卡型号：

- 讯威 SRND-CM-TR1616。支持16路开关量输入，16路晶体管输出。
- 讯威 SRND-CM-IO1616。支持16路开关量输入，16路继电器输出。

接线方式如下：

- 扩展板卡的Vcc连接至控制柜前面板的V+。
- 扩展板卡的GND连接至控制柜前面板的V–。
- 扩展板卡的RS485A连接至控制柜底面板的M_A或S_A。
- 扩展板卡的RS485B连接至控制柜底面板的M_B或S_B。

.. note::

   机器人做主站，则连接至M_A和M_B；机器人做从站，则连接至S_A和S_B。

接线完成后，需在 |软件| 软件配置，具体操作见 |软件| 软件用户手册。
